MUSCLEFORGE IPHONE EDITION v5

Update GitHub Pages by uploading all files from this folder into the SAME repository directory as v4. Keep the same URL to preserve local data. Export a JSON backup in Settings first.

On iPhone: open the GitHub Pages URL in Safari, then Share > Add to Home Screen. If the old interface persists, reload in Safari and reopen the Home Screen app.

The workout logger now features a focused one-exercise-at-a-time screen, progress indicator, exercise selector, thumb-friendly set inputs, rest timer and next-exercise flow. All other v4 features remain.

Data remains local to this browser/PWA. No cross-device synchronization or guaranteed background notifications. Tutorial links open third-party websites.
